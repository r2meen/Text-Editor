Important: Test Replace All with words that have different replacement lengths. This helps detect position and undo errors.

6. Undo test cases

Use Option 8 – Undo Last Operation.

Test	Action before undo	    Expected result
U1	    Add a new line	        Added line disappears
U2	    Insert text	            Inserted text disappears
U3	    Delete text	            Deleted text returns
U4	    Replace First	        Original word returns
U5	    Replace All	            All replaced words return
U6	    Undo repeatedly	        Each operation reverses in the correct order
U7	    Undo on empty history	Displays an appropriate message

Especially test U5: Replace All, then Undo. Check that every original word is restored, even when the replacement has a different length.
