# TEXT EDITOR – FILE MANAGEMENT GUIDE

## 1. Introduction

The Text Editor provides file management functionality that allows users to create, open, edit, and save text documents.

The four main file management operations are:

1. New Document
2. Open File
3. Save File
4. Save As

## 2. Menu Options

| Option | Function |
|---|---|
| 10 | New Document |
| 11 | Open File |
| 12 | Save File |
| 13 | Save As |
| 14 | Exit |

## 3. File Management Features

### A. New Document (Option 10)

- Clears the current document.
- Resets the current filename.
- Clears the Undo history.
- Creates a new empty document.

### B. Open File (Option 11)

- Asks the user to enter a filename or file path.
- Opens an existing text file.
- Reads the file line by line.
- Loads its contents into the editor.
- Displays an error message if the file cannot be opened.

### C. Save File (Option 12)

- Saves the current document to its existing filename.
- If no filename exists, it uses the Save As functionality.
- Writes the document contents into the file.
- Displays a success or error message.

### D. Save As (Option 13)

- Asks the user to enter a new filename or file path.
- Saves the current document under the specified filename.
- Updates the current filename after successful saving.
- Displays a success or error message.
